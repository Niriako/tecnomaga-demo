# Tecnomaga (demo)

Demo jogável de combate no navegador: movimento, pulo duplo, combo de 3 golpes (Z) e a skill Pulso Arcano (A).

Controles: setas para andar, Shift para correr, C para pular, Z para atacar, A para a skill. No celular há botões na tela.

Personagem, cenário e efeitos são provisórios.
